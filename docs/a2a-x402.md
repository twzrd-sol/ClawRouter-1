# A2A x402 compatibility

ClawRouter exports a transport-neutral A2A x402 state machine for paid
agent-to-agent services. It maps an A2A `input-required` task to the existing
ClawRouter policy-before-sign path, then carries a correlated
`payment-submitted` message and an append-only receipt history.

```ts
const merchant = new A2AX402Merchant({
  verifier: verifyWithWalletOrFacilitator,
  settle: settleWithFacilitator,
});
const task = merchant.createTask("task-123", {
  x402Version: 1,
  accepts: [{
    scheme: "exact",
    network: CAIP2_BASE,
    asset: "USDC",
    payTo: "0x...",
    amount: "10000",
    maxTimeoutSeconds: 600,
  }],
});

const client = new A2AX402Client({
  spendControl,
  signer: signWithWallet,
});
const submission = await client.createPaymentSubmission(task);
const completed = await merchant.receivePayment(submission);
```

The client checks expiry and `SpendControl` before calling the signer. The
merchant retains the original requirement by `taskId`, checks the requirement
hash, network, nonce, and signature, and appends every success or failure
receipt. `createHmacA2ASigner` and `createHmacA2AVerifier` are hermetic test
helpers only; they are not production wallet implementations.

Run the focused compatibility test with:

```bash
npm run test:a2a
```

This is a no-chain adapter. A production integration must supply a real wallet
signer and facilitator verifier/settler, and should preserve the A2A extension
URI and `taskId` correlation defined by the v0.1 specification.
